## Project starting point

The `main` branch contains the Tenant Portal starter baseline. Students clone it and publish their work to their own empty public repository.

```bash
git clone https://github.com/Zwang-23/SEG4105_Lab6.git SEG4105_Lab6
```

Follow Exercise 1 to configure `upstream` as the instructor source and `origin` as your own submission repository.

## Repository branches

- [main](https://github.com/Zwang-23/SEG4105_Lab6/tree/main): starter project to clone.
- [lab-guide](https://github.com/Zwang-23/SEG4105_Lab6/tree/lab-guide): instructions and student downloads.
